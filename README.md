# HARSHA MARISHETTY Portfolio

## Resume download fix
The resume is now embedded directly inside `index.html` as PDF data. The Download Resume button creates the PDF in the browser and downloads it as:

`Harsha_Marishetty_Resume.pdf`

This removes the dependency on a relative PDF path and fixes the `ERR_FILE_NOT_FOUND` issue when opening the portfolio locally.

## Important
Open `index.html` normally after extracting the ZIP. No web server is required.

The original PDF is also included in the folder as a backup/reference.
